# 🇰🇪 NYOTA Fund Clone Website

A digital application portal clone of Kenya's NYOTA Fund (National Youth Opportunities Towards Advancement) - a KSh 5 Billion government initiative in partnership with the World Bank.

## 📋 Overview

This project is a fully functional web application that mimics the NYOTA Fund application process. It provides youth with a digital interface to check eligibility, submit applications, and track county rollout status.

**Official Program Details:**
- **Amount:** Up to KSh 50,000 non-repayable grant
- **Partner:** Government of Kenya + World Bank
- **Official USSD:** `*254#`
- **Target:** Youth aged 18-35 years

## ✨ Features

| Feature | Description |
|---------|-------------|
| ✅ Eligibility Checker | Age, education, employment, and ID verification |
| 📝 Application Form | Complete digital application submission |
| 🗺️ County Rollout Tracker | Real-time status of active counties |
| 📱 Mobile Responsive | Works perfectly on all devices |
| ⚠️ Scam Alert System | Warns users about fraudsters |
| 💾 Local Storage | Applications saved in browser |
| 🔄 No Server Required | Runs entirely offline |
